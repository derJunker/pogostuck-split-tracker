Hi! Ty for using my Program :)

Seems like you are using fullscreen. Sadly the overlay does not work with fullscreen - only windowed or borderless☹️. You can still use the program to track your gold splits etc, or move the overlay to a 2nd monitor. But sadly there is no way of putting it on top of the game.

Before you can use the splits-program, you need to set up a few things.

  • Add Steam Launch Option: You need to add "-diag" as a launch option to your Pogostuck Steam launch configuration. This is needed so the game writes the logs that this program reads for split detection, etc..
    To do this, right-click on Pogostuck in your Steam Library, go to Properties, then Launch Options and add "-diag" (without quotes) to the text field.
    Alternatively: Launch Pogostuck with the "Launch Pogostuck" button in this program - after everything is setup correctly. This will launch Pogostuck with the mentioned launch option.
  • Launch Pogostuck: Launch Pogostuck (via Steam). It will try to find the path to your Pogostuck installation and your userdata path. However, this does not always work, especially if you have Pogostuck installed on a different drive than Steam. Check the Paths tab to see if the paths are correct, or it should give you feedback in the overlay if anything is wrong. If one or both paths are not filled out OR you have multiple steam accounts with pogostuck owned, you need to follow the next two steps.
  • Pogo Path: You need to input your Pogostuck path (in the Paths tab). It is needed for basically everything. In there the before mentioned logs are put.
    It should be looking similar to this:
    C:\Program Files (x86)\Steam\steamapps\common\Pogostuck
    You can also this path when you go to the Pogostuck steam library page, click on the settings wheel -> manage -> browse local files.
  • Steam Path: You need to input your Steam path (in the Paths tab as well). It is used to read your Settings.txt within, so it can read your current split times.
    Most likely it will be something similar to this:
    C:\Program Files (x86)\Steam\
  • Steam Friend Code: You need to input your Steam Friend code (in the Paths tab once again). It is necessary for to find the Settings.txt
    Most likely it will be 5-10 digits long. You can find it at "Add Friend" Section in Steam.
  • Adjust Speedrun splits ingame: In pogostuck Options -> Misc -> Show speedrun splits -> set it to "Minimal", "Off" won't work.
  • Enter Pbs: Currently i dont have a way to automatically detect your Pbs. So you have to enter it manually. So you need to do that under the Pbs tab.
  • Enter Split Skips: If you skip any full splits (e.g. palms skip, mushroom skip or in extra modes like puzzle & double jump), you need to enter them in the Splits tab. Otherwise the sum-of-best-splits cannot be calculated properly.
  • Windows 11 Users: If you are using Windows 11 and have window shadow enabled, you can choose to disable it in these settings.

If you have difficulties with this setup, consider watching this Youtube setup-guide or just contact me ;).

Preference Configuration Suggestions

  • If you play fullscreen, you cannot use the split overlay. However you can have it on a second monitor or running in the background.
    If you choose to have it on a second monitor, you should set "Enable background color" to true, and then set your background color.
  • If you play borderless, after resizing and dragging the overlay to the desired position set "Overlay is not clickable" to true, this way you will able to click stuff behind the overlay.
  • If you stream and want to use this overlay. Set "Hide overlay when Pogostuck not active" to false, so the overlay does not disappear when you tab out.
  • To reduce the amount of programs you need to open, set the "Launch Pogostuck on startup" to true, so you can just open this program and it will launch Pogostuck for you.

フルスクリーンモードをご利用中のようです。残念ながら、スプリットのオーバーレイはウィンドウモードまたはボーダーレスモードのみ対応しています☹️。区間PBの記録などは問題なく作動しますが、フルスクリーンモードでオーバーレイを利用するためにはオーバーレイをサブモニターに移動する必要があります。ゲーム上に直接表示させる方法はありません。

スプリットプログラムを使用する前に、幾つかの設定が必要です。

  • Steam起動オプションを追加： PogostuckのSteam起動オプションに「-diag」を追加してください。このオプションにより、ゲームがログファイルを作成し、プログラムがスプリット などを探知することが可能になります。
    方法：SteamのライブラリでPogostuckを右クリック → プロパティ → 起動オプションに「-diag」（引用符なし）を追加
    起動オプションが正しく設定されたら、このプログラムのLaunch Pogostuckボタンを通じてもPogostuckを起動できます。
  • Pogostuckを起動： SteamからPogostuckを起動してください。インストールパスとuserdataパスの自動検出を行います。
    PogostuckとSteamが違うドライブにインストールされている場合などはパスの検出に失敗することがあります。
    パスタブでパスが正しいか確認してください。問題がある場合はスプリットのオーバーレイに解決のためのフィードバックが表示されます。
    どちらかのパスが未設定の場合、または複数のSteamアカウントでPogostuckを所有している場合は、次の手順に従ってください。
  • Pogo Path： パスタブでPogostuckのインストールパスを入力してください。これはスプリットプログラムの作動に必修です。このパスにゲームのログファイルが出力されます。
    一般的には以下のようなパスになります：
    C:\Program Files (x86)\Steam\steamapps\common\Pogostuck
    PogostuckのSteamライブラリでPogostuckを右クリック → 管理 → ローカルファイルを参照→ パスをコピー
  • Steam Path： パスタブでSteamのインストールパスを入力してください。これはSettings.txtを読み込み、現在のスプリットタイムを取得するために必要です。
    一般的には以下のようなパスになります：
    C:\Program Files (x86)\Steam\
  • Steam フレンドコード： パスタブでSteamのフレンドコードを入力してください。これもSettings.txtを探すために必要です。
    通常は5~10桁の数字となっています。Steamのフレンド追加メニューで確認できます。
  • ゲーム内でスプリットを調整: Pogostuckのオプション → その他 → タイムアタックのスプリットを表示を「プラスマイナスのみ」に設定してください。「オフ」では動作しません。
  • PBを入力: 現時点ではPBの自動探知は対応していません。Pbsタブで手動で入力してください。
  • スプリットスキップを入力： パルムスキップ、きのこスキップ、またはパズルやダブルジャンプのモードでのスキップなどをする場合、スプリットタブにスキップを入力してください。入力されないと、区間PBの合計が正しく計算されません。
  • Windows 11を利用してる方へ： Windows 11でウィンドウの下の影が表示になっている場合は、設定から非表示に変えれます。

セットアップに問題がある場合は、このYoutubeセットアップガイドを参照するか、私に連絡してください ;).

おすすめの設定

  • フルスクリーンモードでプレイする場合、スプリットのオーバーレイは基本使用できません。サブモニターやゲーム裏で表示させることは可能です。
    サブモニターで使用する場合は、Enable background colorを「true」に設定し、背景色を指定することをおすすめします。
  • ボーダーレスモードでプレイする場合、スプリットのオーバーレイのサイズと位置の調整をした後、Overlay is not clickableを「true」に設定してください。これによってオーバーレイ越しにクリックすることが可能になります。
  • 配信をしてる場合、オーバーレイを配信に移したいならHide overlay when Pogostuck not activeを「false」に設定してください。これによってPogostuckが非アクティブになってもオーバーレイは消えません。
  • 起動するプログラムの数を減らしたい場合は、Launch Pogostuck on startupを「true」に設定すると、このプログラムを起動するだけでPogostuckも自動的に起動されます。

Overlay Behavior オーバーレイの動作
When enabled, it makes the overlay clickthrough. When playing borderless this should be enabled after you set it up properly. 有効にするとオーバーレイをクリック不可にします。ボーダーレスモードでプレイする場合は、設定が完了した後に有効にしてください。
When enabled, the overlay will hide when Pogostuck is not the active window. Disable this if you want to use the overlay while streaming. 有効にするとPogostuckがアクティブでないときにオーバーレイを非表示にします。配信中にオーバーレイを使用したい場合は無効にしてください。
When enabled, Pogostuck will be launched when you open this program. 有効にすると、このプログラムを起動したときにPogostuckも起動します。
Splits スプリット
Changes the times in the split overlay to the pace your golden splits would have. スプリットオーバーレイのタイムをゴールドスプリットのペースに変更します。
Hide splits that selected to skip in a run. If disabled they are greyed out. 走行中にスキップするよう選択したスプリットを非表示にします。無効にするとグレー表示されます。
When enabled, split names will remain white. Only the time differences will be colored. 有効にすると、スプリット名は白のままになります。差分のタイムのみが色表示されます。
Shows the amount of resets per split you did in the overlay (resets are still tracked when this option is disabled). オーバーレイに各スプリットのリセット回数を表示します（このオプションが無効でもリセットは追跡されます）。
Will show / hide the Sum-of-Best in the overlay. オーバーレイにSoBを表示/非表示にします。
Will show / hide the "Pace" in the overlay. オーバーレイにペースを表示/非表示にします。
Reverse the split order for upside-down mode in the overlay. オーバーレイで逆さま逆転モードのスプリット順を逆にします。
Design デザイン
Let's you set a background color. This is helpful if you have the overlay on a 2nd monitor instead of over Pogostuck. 背景色を設定できます。オーバーレイをPogostuckの上ではなく、2番目のモニターに表示する場合に便利です。

Gold Splits ベストスプリット This shows your gold splits for your selected run. This path changes when you select to skip a split. これは選択した走行のベストスプリットを表示します。スプリットをスキップするよう選択すると、このパスが変わります。

Best Split-Paces ベストスプリットペース This shows the best times you reached each split. In a run the split in the overlay will be blue, if you improve that time. これは各スプリットで達成したベストタイムを表示します。走行中にオーバーレイのスプリットが青くなると、そのタイムを更新したことになります。

Split Skips スプリットスキップ Here you need to select which splits you are going to skip in a run. Otherwise the sum of best, pace and gold split calculations won't work. ここで、走行中にスキップするスプリットを選択する必要があります。 そうしないと、Sum of Best、Pace、Gold Splitの計算が正しく機能しません。

Set this, if your mode includes rubberbanding. This will subtract the 1h penalty. 紐ポゴが含まれるモードの場合はこれを設定してください。1時間のペナルティが差し引かれます。
